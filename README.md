# Prompt da animação no Google Flow

Página de Augusto Fonte: a pessoa preenche a ideia, copia o prompt e cola no Claude Code.

Publicada em https://augustofonteboa-maker.github.io/prompt-animacao-flow/

Site estático, sem build. O texto do prompt fica na constante `MODELO` e as lacunas em `LACUNAS`, no fim do `index.html`. Cada lacuna precisa existir igual dentro do `MODELO`.
